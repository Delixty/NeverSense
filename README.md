# NeverSense UI Library for Roblox
Современная, оптимизированная клиентская UI-библиотека для Roblox в стиле Dark Minimal Neo-Glow (черно-красная палитра). Библиотека разработана для создания структурированных меню с адаптивной версткой, плавной анимацией и поддержкой кастомных биндов клавиш.

Особенности
Dark Neo-Glow Design: Чистый минималистичный интерфейс в глубоких темно-серых и матово-черных тонах с неоново-красными акцентами (UIStroke и кастомные шейп-контуры).

TweenService Animations: Плавное открытие/скрытие окон, переключение вкладок и анимация нажатия кнопок.

Правильное наложение (DisplayOrder): Меню корректно отображается поверх стандартных игровых интерфейсов.

Система категорий и вкладок: Структурированное разделение (Combat, Visuals, Movement, Config, Info).

Модуль Keybind: Настраиваемая привязка клавиш на UserInputService для скрытия и открытия меню.

Встроенная палитра цветов: Компактный выбор цвета и готовые цветовые пресеты без перегрузки интерфейса лишними ползунками.
